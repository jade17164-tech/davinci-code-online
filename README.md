# 다빈치 코드 온라인 (Da Vinci Code Online)

보드게임 **다빈치 코드**를 웹 브라우저에서 즐길 수 있는 온라인 멀티플레이 게임입니다.
HTML 파일 하나로 동작하며, 실시간 통신은 Firebase Realtime Database를 사용합니다.

## 기능

- **개인전 (2~6인)** / **2:2 팀전 (4인 전용)** 두 가지 게임 모드
- 타일 분배 방식 선택
  - 인원수별 자동 조절 (2~4인: 4장 / 5~6인: 3장)
  - 무조건 3장씩 시작
  - 무조건 4장씩 시작
- 모드 및 분배 방식별로 방이 분리되어 매칭
- 모바일 화면 대응

## 플레이 방법

1. 방을 만들거나 참가합니다.
2. 자신의 타일은 숫자가 보이고, 상대 타일은 뒷면만 보입니다.
3. 차례가 되면 타일을 한 장 뽑고, 상대 타일 하나를 지목해 숫자를 추리합니다.
4. 맞히면 그 타일이 공개되고 한 번 더 추리할 수 있습니다. 틀리면 방금 뽑은 타일을 공개하고 차례가 넘어갑니다.
5. 상대의 타일을 모두 맞히면 승리합니다.

## 실행 방법

`index.html` 파일을 브라우저로 열면 바로 실행됩니다.

로컬 서버로 띄우려면:

```bash
python -m http.server 8000
```

이후 브라우저에서 `http://localhost:8000` 으로 접속합니다.

## 기술 스택

- HTML / CSS / JavaScript (프레임워크 없음, 단일 파일)
- Firebase Realtime Database (실시간 동기화)
- Firebase Authentication (익명 로그인)

## 참고

Firebase 웹 설정값(apiKey 등)은 클라이언트에 공개되도록 설계된 값이라 코드에 포함되어 있습니다.
다만 데이터 보호는 **Firebase 콘솔의 보안 규칙(Security Rules)** 으로 해야 하므로,
규칙이 테스트 모드(누구나 읽기/쓰기 허용)로 열려 있지 않은지 확인하는 것을 권장합니다.
